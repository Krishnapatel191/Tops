Q-1 : Create a class called Song in your preferred OOP language with private properties title and artist. Add public getter and setter methods to access and modify these properties, then create an object and update its title.
Ans.
#include <iostream>
using namespace std;

class Song
{
private:
    string title;
    string artist;

public:
    void setTitle(string t)
    {
        title = t;
    }

    void setArtist(string a)
    {
        artist = a;
    }

    string getTitle()
    {
        return title;
    }

    string getArtist()
    {
        return artist;
    }
};

int main()
{
    Song song;

    song.setTitle("Perfect");
    song.setArtist("Ed Sheeran");

    cout << "Title: " << song.getTitle() << endl;
    cout << "Artist: " << song.getArtist() << endl;

    song.setTitle("Shape of You");

    cout << "\nUpdated Title: " << song.getTitle() << endl;

    return 0;
}

Output:
Title: Perfect
Artist: Ed Sheeran

Updated Title: Shape of You





Q-2 : Build a class called InstaStory with a protected property storyViews. Create a subclass called SponsoredStory that can access and display the storyViews value.
Ans.
#include <iostream>
using namespace std;

class InstaStory
{
protected:
    int storyViews;

public:
    InstaStory()
    {
        storyViews = 500;
    }
};

class SponsoredStory : public InstaStory
{
public:
    void displayViews()
    {
        cout << "Story Views: " << storyViews << endl;
    }
};

int main()
{
    SponsoredStory story;

    story.displayViews();

    return 0;
}

Output:
Story Views: 500





Q-3 : Imagine a Flipkart-like app: create an abstract class Product with an abstract method upload(). Then, create two subclasses, Electronics and Clothing, that each implement the upload() method to print a different upload message.
Ans.
#include <iostream>
using namespace std;

class Product
{
public:
    virtual void upload() = 0;
};

class Electronics : public Product
{
public:
    void upload() override
    {
        cout << "Uploading Electronics product to Flipkart." << endl;
    }
};

class Clothing : public Product
{
public:
    void upload() override
    {
        cout << "Uploading Clothing product to Flipkart." << endl;
    }
};

int main()
{
    Electronics e;
    Clothing c;

    e.upload();
    c.upload();

    return 0;
}

Output:
Uploading Electronics product to Flipkart.
Uploading Clothing product to Flipkart.

Q-5 : Explain in your own words the difference between encapsulation and abstraction, using examples from any social media app you use daily (like Instagram or WhatsApp).
Ans.
Encapsulation means protecting data by keeping it private and allowing access only through specific methods.
For example, in Instagram, a user's private messages (DMs) are protected. Users cannot directly access the internal data of the messaging system. The app controls how messages are stored and accessed. This is encapsulation.

Abstraction means hiding the complex internal process and showing only the required features.
For example, when we upload a photo on Instagram, we simply select a photo and click the Post button. We do not need to know how Instagram processes the photo, uploads it to the server, or stores it in the database. This is abstraction.

In simple words:

Encapsulation = Protecting data.
Abstraction = Hiding complex processes.
